# Boost 1.62.0 for iOS

Boost 1.62.0 was released in September 2016. This package preserves the same
compiled-library selection as the 1.61.0 package and adds the complete 1.62.0
header tree.

## New in Boost 1.62.0

- **QVM** is a new header-only library for static-size quaternions, vectors and
  matrices, particularly useful for graphics, games, video and simulation. It
  is available in this package through the included headers.
- **Fiber** is a new compiled library for user-space cooperative threads. It is
  not in the combined binary yet because it depends on Boost.Context and needs
  dedicated runtime coverage for arm64 devices and arm64/x86_64 Simulators.

## Relevant updates

- Boost.Regex fixes include invalid-expression safety, case-sensitivity and ICU
  detection improvements.
- Boost.Thread includes fixes to futures, barriers and several lock types.
- Boost.Container adds early forms of several later C++17 map and node APIs,
  although its compiled library is not selected in this package.
- Boost.Coroutine is deprecated in favour of Boost.Coroutine2. Neither is in
  the binary until the architecture-specific Boost.Context path is tested.
- Boost.Log adds optional inter-process logging tools, but remains excluded from
  this iOS-oriented binary due to its size and platform-specific backends.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

# Boost 1.70.0 for iOS

Boost 1.70.0 was released on April 12, 2019. This package carries forward the
nine baseline compiled libraries plus Boost.Context, includes the complete
updated header tree, and uses C++17.

## New in Boost 1.70.0

- **Histogram** adds header-only, multidimensional histogram construction and
  accumulation. Basic axis creation and bin updates are smoke-tested.
- **Outcome** adds lightweight result and outcome types for explicit value or
  failure handling. Basic result value handling is smoke-tested.

## Relevant updates

- Boost.Context and header-only Boost.Coroutine2 retain their architecture and
  runtime coverage. The complete Boost 1.70 smoke suite passed on an arm64 iOS
  Simulator and physical arm64 iOS device.
- Header-only Boost.Signals2 remains the supported slot-dispatch path after the
  upstream removal of legacy compiled Boost.Signals in 1.69.
- Boost.Fiber and deprecated compiled Boost.Coroutine remain excluded until
  they receive dedicated device and Simulator runtime coverage.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.70.0/

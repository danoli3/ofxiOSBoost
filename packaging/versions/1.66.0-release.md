# Boost 1.66.0 for iOS

Boost 1.66.0 was released in April 2018. This package preserves the
same compiled-library selection as 1.65.0 and includes the complete updated
header tree. It continues the C++14 standard policy for this version range.

## Relevant updates

- Boost.Asio receives portability and correctness improvements available
  through the complete header tree.
- Boost.Thread and Boost.Regex maintenance fixes are carried forward.
- Boost.Context, Boost.Log and Boost.Coroutine/Coroutine2 remain
  excluded pending the same architecture-specific testing noted in
  `COMPONENTS.md`.

The compiled-library set is intentionally conservative for this release.
Future updates may add compiled libraries after iOS device and Simulator
validation.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release notes: https://www.boost.org/users/history/version_1_66_0.html

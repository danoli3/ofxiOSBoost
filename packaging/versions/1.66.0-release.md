# Boost 1.66.0 for iOS

Boost 1.66.0 was released on December 18, 2017. This package carries forward
the ten baseline compiled libraries plus Boost.Context from 1.65.0 and includes
the complete updated header tree. It continues the C++14 standard policy for
this version range.

## Relevant updates

- New header-only libraries Boost.Beast, Boost.CallableTraits and Boost.Mp11
  are present. The example app adds offline smoke coverage for all three.
- Boost.Asio includes its 1.66 Networking TS API transition; the example keeps
  an offline callback test to catch integration regressions.
- Boost.Regex includes upstream security and fuzz-testing fixes, with further
  maintenance fixes across DateTime, Thread, PolyCollection and Stacktrace.
- Boost.Context retains the explicit AAPCS arm64 and SysV x86_64 Mach-O
  configuration validated for 1.65. Coroutine2 remains header-only and runs on
  the included Context binary. The complete 1.66 suite passed on an arm64
  Simulator and a physical arm64 iOS device.
- Boost.Fiber and deprecated compiled Boost.Coroutine remain excluded until
  they receive their own runtime coverage.

The compiled-library set is intentionally conservative for this release.
Future updates may add compiled libraries after iOS device and Simulator
validation.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

See `packaging/versions/1.66.0-validation.md` in the source repository for the
current Simulator and device runtime-validation record.

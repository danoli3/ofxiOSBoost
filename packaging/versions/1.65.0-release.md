# Boost 1.65.0 for iOS

Boost 1.65.0 was released in September 2017. This package preserves the
1.64.0 compiled-library selection plus Boost.Context and includes the complete
updated header tree. It moves the C++ standard to C++14
(`1.65.0` is the first release built with `c++14` per
`AGENTS.md` / `scripts/build-boost-ios`).

## New in Boost 1.65.0

- **Stacktrace** is a new compiled library providing portable stack
  trace generation. It is excluded from the combined binary pending
  dedicated iOS device and Simulator runtime tests. Headers remain
  available.
- **PolyCollection** is a new header-only library for polymorphic
  container support. All headers are included.

## Relevant updates

- Boost.Asio receives portability and correctness improvements available
  through the complete header tree.
- Boost.Regex and Boost.Thread maintenance fixes are carried forward.
- Boost.Context is compiled for arm64 devices and arm64/x86_64 Simulators.
  Its `make_fcontext`, `jump_fcontext`, and `ontop_fcontext` assembly is present
  in the release slices. Two real stack round-trips passed at runtime on an
  arm64 Simulator and a physical arm64 iOS device.
- The header-only Boost.Coroutine2 API is available and passed yield/resume
  runtime tests on both the arm64 Simulator and physical arm64 device.
- Boost.Fiber and the deprecated compiled Boost.Coroutine library are separate
  Context dependents. They remain excluded pending their own scheduler and API
  runtime tests. Boost.Log also remains excluded.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.
See `packaging/versions/1.65.0-validation.md` in the source repository for the
device and Simulator runtime-validation record.

# Boost 1.72.0 for iOS

Boost 1.72.0 was released on December 11, 2019. This package carries forward
the nine baseline compiled libraries plus Boost.Context, includes the complete
updated header tree, and uses C++17.

## Boost 1.72.0 updates

- Boost 1.72 introduces no new library. It updates existing libraries,
  including Asio, Beast, Context, Filesystem, Histogram, Outcome, and Variant2.
- Boost.Filesystem moves `filesystem_error` into its compiled library. The
  smoke suite triggers and catches that packaged exception to verify the new
  binary implementation.
- Boost.Histogram's span detection is corrected for modern Apple SDKs so its
  bundled fallback is used in the release's C++17 language mode.
- All earlier version-specific smoke tests remain enabled.
- The complete Boost 1.72 smoke suite passed on an arm64 iOS Simulator and
  physical arm64 iOS device.

## Packaging notes

- Boost.Context and header-only Boost.Coroutine2 retain their validated
  architecture configuration.
- Header-only Boost.Signals2 remains the supported slot-dispatch path.
- Boost.Fiber and deprecated compiled Boost.Coroutine remain excluded until
  they receive dedicated device and Simulator runtime coverage.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.72.0/

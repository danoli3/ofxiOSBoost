# Boost 1.69.0 for iOS

Boost 1.69.0 was released on December 12, 2018. This package carries forward
the nine remaining baseline compiled libraries plus Boost.Context, includes the complete
updated header tree, and uses C++17.

## New in Boost 1.69.0

- **Safe Numerics** adds header-only checked integer arithmetic that detects
  invalid operations and conversions. Its headers are included, but current
  Apple Clang rejects this release's `safe_compare` implementation; dedicated
  runtime coverage is deferred until a later Boost release fixes it.

## Relevant updates

- Boost.Context and header-only Boost.Coroutine2 retain the validated
  architecture-specific runtime coverage from Boost 1.68.0.
- Legacy compiled Boost.Signals was removed upstream. The smoke suite moves to
  its header-only successor, Boost.Signals2.
- Boost.Beast, Asio, Filesystem, Graph, Locale, Regex, Thread, and the other
  packaged or smoke-tested libraries receive their 1.69 maintenance updates.
- Boost.Fiber and deprecated compiled Boost.Coroutine remain excluded until
  they receive dedicated device and Simulator runtime coverage.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.69.0/

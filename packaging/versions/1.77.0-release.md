# Boost 1.77.0 for iOS

Boost 1.77.0 was released on August 5, 2021. This package remains on C++17 and
carries forward the validated compiled Context, Nowide, JSON, and Serialization
configuration.

## New and updated coverage

- **Describe**, new in 1.77, reflects over named public struct members.
- **Lambda2**, new in 1.77, evaluates a compact placeholder expression.
- **JSON** converts a fixed-size `std::array` and exercises its new standard
  hash specialization.
- **Filesystem v4** is explicitly selected in the 1.77 smoke translation unit
  and validates its changed hidden-file stem and extension semantics. The same
  compiled binary continues to support the default v3 API.
- **Locale** retains the iOS SDK iconv cross-compilation fix introduced for the
  1.76 package.

All Boost headers are packaged, and the complete existing Context, Coroutine2,
Nowide, JSON, Serialization, and compiled-library regression suite remains
enabled. The complete suite passed on an arm64 iOS Simulator and physical arm64
iOS device.

Upstream release: https://www.boost.org/releases/1.77.0/

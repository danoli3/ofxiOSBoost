# Boost 1.64.0 for iOS

Boost 1.64.0 was released in April 2017. This package preserves the
1.63.0 compiled-library selection and includes the complete updated header
tree. It is the last release in this repository built with C++11
(`1.65.0` moves to C++14 per `AGENTS.md` / `scripts/build-boost-ios`).

## New in Boost 1.64.0

- **Process** is a new compiled library for managing child processes.
  It is not in the combined binary yet because process creation on iOS
  requires a dedicated spawn/fork and entitlement audit for arm64 devices
  and arm64/x86_64 Simulators. Headers remain available.

## Relevant updates

- Boost.Asio, Boost.Beast (newly proposed at this time, header-only) and
  Boost.Filesystem receive portability and correctness fixes available
  through the complete header tree.
- Boost.Regex and Boost.Thread maintenance fixes from 1.63 are carried
  forward.
- Boost.Log, Boost.Context and Boost.Coroutine/Coroutine2 remain excluded
  pending the same architecture-specific testing noted in `COMPONENTS.md`.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.64.0/

# Boost 1.71.0 for iOS

Boost 1.71.0 was released on August 19, 2019. This package carries forward the
nine baseline compiled libraries plus Boost.Context, includes the complete
updated header tree, and uses C++17.

## New in Boost 1.71.0

- **Variant2** adds a header-only, never-valueless variant implementation with
  strong exception guarantees. Alternative selection and visitation are
  smoke-tested.

## Relevant updates

- Boost.Context and header-only Boost.Coroutine2 retain their validated
  architecture configuration and runtime coverage. The complete Boost 1.71
  smoke suite passed on a physical arm64 iOS device; Simulator runtime
  confirmation remains pending.
- Header-only Boost.Signals2 remains the supported slot-dispatch path after the
  upstream removal of legacy compiled Boost.Signals in 1.69.
- Boost.Fiber and deprecated compiled Boost.Coroutine remain excluded until
  they receive dedicated device and Simulator runtime coverage.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.71.0/

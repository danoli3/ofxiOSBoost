# Boost 1.63.0 for iOS

Boost 1.63.0 was released in December 2016. It adds no new Boost library, so
this package preserves the 1.62.0 compiled-library selection and includes the
complete updated header tree.

## New and relevant in Boost 1.63.0

- **TypeIndex** adds `runtime_cast`, a header-only alternative to
  `dynamic_cast` for projects where conventional RTTI is unavailable or
  undesirable. The XCFramework and Swift-package examples exercise it on every
  packaged architecture.
- **Atomic** adds `atomic<T>::is_always_lock_free` for alignment with the C++17
  atomic interface. Native `int` operations are tested on arm64 devices and
  arm64/x86_64 Simulators without adding the compiled fallback library.
- **Log** can now report the active text-sink file name, but remains excluded
  from the combined binary because of its size and desktop-oriented backends.
- **TypeIndex**, **Container**, **Intrusive**, **Interprocess**, **Lexical Cast**
  and **Unordered** receive portability, correctness or allocator fixes that
  are available through the complete header tree.

Boost.Atomic's post-release warning concerns 64-bit atomic operations on 32-bit
x86 with older GCC-compatible compilers. This package contains neither a 32-bit
slice nor GCC-built binaries, so it does not affect the supported targets.

See `COMPONENTS.md` for the complete compiled-library inventory. All Boost
headers are included even when a corresponding compiled library is omitted.

Upstream release: https://www.boost.org/releases/1.63.0/

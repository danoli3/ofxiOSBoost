# Boost 1.91.0 for iOS

Boost 1.91.0 was released on April 22, 2026. This package remains on C++20
with an iOS 12.0 deployment target.

## New libraries

Boost.Decimal implements IEEE 754 decimal floating-point numbers. Upstream
declares it as a header-only CMake interface target, so all headers are packaged
and no static archive is added. Dedicated deterministic coverage exercises
exact decimal arithmetic and decimal character conversion.

## Packaged libraries

The Boost 1.90 compiled set carries forward unchanged. Boost.System remains
header-only, while Charconv, Cobalt, and the portable basic Stacktrace backend
remain compiled. Redis retains its separate-compilation consumer model. Process
v2 remains excluded pending dedicated iOS process-spawning validation.

## Validation scope

The complete earlier regression suite is retained. Release-specific coverage
adds Boost.Decimal arithmetic and character conversion, the Charconv negative
128-bit regression, UUID character conversion, URL query/decode conveniences,
and System `result::unsafe_value`. Three-slice packaging, standalone
XCFramework, SwiftPM, local CocoaPods, and the complete runtime suite on an
arm64 Simulator and physical arm64 iOS device pass.

The upstream release notes were audited in full. Platform-specific Windows,
Cygwin, CUDA, PowerPC, OpenSSL, and non-Apple Unix changes are packaged where
header-based but are outside this iOS validation scope. Network-dependent Redis
Sentinel/PubSub behavior remains offline/deferred; its existing deterministic
RESP3 separate-compilation coverage is retained.

Upstream release: https://www.boost.org/releases/1.91.0/
